# yor_interface

Web control hub for the YOR robot (Raspberry Pi + Jetson Orin): start/stop
robot processes in tmux, live terminals, health checks, Claude agents, from
any browser.

- [PI.md](PI.md): Pi-side plan, architecture, and the shared hub API contract
- [ORIN.md](ORIN.md): Orin-side brief and status

Branches: `pi` (Pi agent), `orin` (Orin agent), `main` (merged / shared).
